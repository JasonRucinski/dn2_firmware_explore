Digitone II Mods / waverider

Waverider

A sixth synth machine for the Digitone II. Waverider has two wavetable oscillators, a sub-oscillator and a noise generator. MOVE sweeps each oscillator through its table. You put the tables on the +Drive with DNX.

Build it

The page builds the file again and signs it with a key from your own file. Then the page does all the integrity checks again. If one check fails, the page does not let you download the file.

Get DNX

DNX also runs in your browser. Use DNX to back up the +Drive and to put wavetables from WAV files on it. DNX also controls the pool of each project. When you go back to stock, DNX erases the Waverider data.

Install the file on the unit

  1. Back up the +Drive with DNX.
  2. Open Elektron Transfer.
  3. Connect the Digitone II to the computer with a USB cable.
  4. Drag the patched file onto the Digitone II in Transfer. The unit updates and starts again.
  5. Make sure that MACHINE SEL shows WAVERIDER after SWARMER.

No other steps are necessary. At first, the +Drive has no wavetables. When you add the first table with DNX, the unit prepares the storage.

Before you start

  • Use Digitone II OS 1.11 only.
  • First, use Waverider alone, on a new project. If a problem occurs, we then know that the cause is Waverider and not a combination of mods.
  • When you report a problem, tell us which mods are in your file.
  • If the unit does not start:
    1. Push and hold FUNC when you turn on the power.
    2. Open the Early Start-up Menu.
    3. Do an OS upgrade with the stock 1.11 file over MIDI DIN.

Select Waverider

WAVERIDER is in MACHINE SEL, after SWARMER. A Waverider track has five SYN pages. The header shows Waverider (1/5) to Waverider (5/5).

Pages 1 and 2: the oscillators

Page 1 is for oscillator 1. Page 2 is for oscillator 2. The two pages have the same controls.

KnobControlFunction
ATUNE / DETNThe pitch in semitones. TUNE changes the pitch of the two oscillators. DETN is the difference from oscillator 1
BLEVThe level, 0 to 127. At 100, the gain is 1
CPOSThe position in the table, 0 to 120
DTBLThe table: Prim., Harm., then the pool tables from T:001
ERATEThe speed of MOVE, 0 to 100. When SYN1 or SYN2 is on, RATE shows a note length
FMLEVHow much MOVE decreases the level, 0 to 127. At 0, MOVE does not change the level
GMPOSHow much MOVE changes the position, 0 to 100. At 50, MOVE does not change the position
HMOVEThe shape that MOVE follows. There are eleven shapes

The wave shows only one voice. Usually, this is the voice of the newest note. If not, it is the first voice that the page selected. The unit calculates all the voices, and you hear all of them. One cursor for each note is in "Plans".

There are eleven MOVE shapes. These five shapes stop at their end: Ramp Up, Ramp Down, Exp Up, Exp Down and Tri Once. These six shapes repeat: Up Loop, Down Loop, Tri Loop, Square, Rnd Hold and Rnd Glide.

Page 3: sub and noise

KnobControlFunction
ASUBThe level of the sub-oscillator, 0 to 127. At 0, the sub-oscillator is off
BOCT-1, -2 or -3 octaves below the oscillator that it follows
CWAVEThe wave: SIN, TRI, SQR or PLS (a 25 % pulse)
DSRCThe oscillator that the sub-oscillator follows: OSC1 or OSC2
ENOISThe level of the noise, 0 to 127. At 0, the noise is off
FTYPEThe noise type: WHT, PNK, BRN or DIG
GCOLRThe tilt of the spectrum, -64 to +63. A negative value adds low frequencies. A positive value removes them
HDECThe decay of the noise after each note, 0 to 126 (5 ms to 10 s). At Inf, the noise stays at full level

The middle of the page shows the sub-oscillator and the noise.

Page 4: sound options

KnobControlFunction
APRSTThe phase at the start of a note: Off, On or Random. With On, the phase starts at 0 and the same note has the same sound each time
BTRIGWith Retrig, MOVE starts again on each note. With Free, MOVE does not start again on a note

The middle of the page shows the sound of the track as a scope.

Page 5: Shape

The top row has FOLD, WARP, FM and NPOS. The bottom row has TYPE, AMT, P1 and P2. These controls are for sound functions in a future version. They do not change the sound now. You can set and p-lock them. The middle of the page shows the scope, as on page 4.

The wavetable pool

  • Tables: each table has 1 to 64 frames. Each frame has 64 to 4096 points, in powers of two. Waverider has two built-in tables: Prim. and Harm.
  • Names: when you turn TBL, the header shows the table name, for example "T:004 name".
  • Add and remove tables: use DNX, or use the wavetable page on the unit. To open the wavetable page, push PRESET/KIT two times. Each project has its own pool of up to 128 tables.
  • Your project file is a normal project: the pool is on the +Drive, next to the project and not in it. Because of this, the stock firmware can load a project that you saved. Its Waverider tracks show as FM Tone, and the stock firmware reads their settings as FM Tone settings. Thus they have a different sound. We examined this in the emulator only, not on an instrument.
  • An empty pool: a project with no pool has no pool tables. Its Waverider tracks play Prim. until you add tables. A new project (CREATE NEW) has an empty pool. A project that you saved before you installed Waverider also has an empty pool.
  • A deleted table: its pool slot shows MISSING and plays Prim. The slot stays until you clear it with CLEAR SLOT. Because the slot stays, a sound that uses the slot does not change to a different table.
  • When you replace a table that plays: the old table continues to play until the new table is ready. Then the old table crossfades into the new table, in the DCLK time. If the first table of a slot is not ready, the slot plays Prim. until the table is ready.

P-locks, LFOs and SAVE

  • P-locks: you can p-lock all the controls on pages 1 to 5. The p-locks stay after a reboot, and after SAVE and LOAD.
  • LFO destinations: all the controls except TYPE, AMT and P1 on page 5 are in the DEST list of the LFO. The controls are in two groups. Each group has the header SYN.

Modulation on the page

When an LFO or MOVE changes POS or TBL, the page shows the value that you hear next to the value that you set. Only POS and TBL show this, on the two oscillators. All other controls show only the value that you set. When a control does not move, the page shows nothing more. The page removes the range about two seconds after the movement stops.

  • Slow, less than 3 Hz: a dot under POS shows the value that you hear. A dotted line shows the range of the sweep. A dotted cursor is under the position bar. The wave is the frame that you hear.
  • Medium, 3 to 12 Hz: the dot is on a grey band. The wave shows the two frames at the ends of the sweep.
  • Fast, more than 12 Hz: the page shows the band and the two frames, but no dot. The symbol ≈ is next to POS.
  • TBL: the wave shows the table that you hear. The label shows the table that you set.

The reason for 3 Hz and 12 Hz: the page updates the screen up to 24 times a second. Up to 3 Hz (1/8 of that rate), the dot moves smoothly. Up to 12 Hz (1/2 of that rate), the dot moves in steps. Above 12 Hz, a dot that moves shows an incorrect, slower movement. For this reason, above 12 Hz the page shows only the range.

We made these captures in the emulator. The emulator does not run LFOs. For this reason, we wrote the value that you hear into the capture by hand. The emulator makes no sound. For this reason, the scopes on pages 4 and 5 show Waverider output that we rendered outside the instrument.

Go back to the stock firmware

  1. In DNX, back up the device.
  2. In DNX, open Settings.
  3. Under Erase the wavetable region, click Erase….
  4. Click Erase the region. DNX saves each table as a file in your DNX folder. Then DNX erases all the stored tables and all the pools from the +Drive.
  5. Flash the stock 1.11 file.

Do steps 1 to 4 before step 5. The stock firmware 1.11 cannot get access to the wavetable region. If you flash the stock firmware first, the data stays on the +Drive. To remove it, flash Waverider again, do steps 1 to 4, and then flash the stock firmware again.

The erase does not change your projects, presets, kits and samples. A project that you saved with Waverider tracks stays on the unit. To put a table back later, drag its file onto a free slot in the Wavetables list of DNX.

Known limits in this alpha

  • Page 5 does not change the sound now.
  • A click may occur if the pool loads again while a note plays on a pool table. If you hear a click, tell us.
  • We did not measure 4096-point tables on the unit.
  • In a sound from a build before page 5, FOLD, WARP, FM and NPOS show 64.

With a 16-note chord, the DSP load of Waverider is almost the same as the load of FM Tone: 65.0 % and 62.9 %. Each bar shows the median load on a Digitone II, from readings of one second, with 16 voices.

A table in the pool uses no DSP time when no voice plays it. The DSP builds a 64x2048 table in about 0.16 s, in time that it does not use for the sound.

How it works

  • The DSP makes the sound. Waverider adds its code to the sound processor (DSP) of the Digitone II. The main processor runs the pages, the pool and the +Drive access.
  • The reader. The unit keeps each table in a set of versions (mip-maps). For higher notes, a version has fewer harmonics. The reader uses a smooth curve between the points (Hermite). Because of this, high notes have no aliasing.
  • The unit builds the tables. When a pool loads, the DSP builds the versions of each table, in time that it does not use for the sound. A 64x2048 table takes about 0.16 s. Until the table is ready, its slot plays Prim.
  • The +Drive store. The tables are in a region of the +Drive that the factory firmware does not read or write. The store keeps two copies of its index. If a write stops before its end, the last good copy stays.
  • Level. The default TRIM is -11 dB. At this value, a new Waverider sound has the same loudness as a new WaveTone sound.

Plans

We plan these functions. We do not give dates, and the order may change.

  • Page 5 changes the sound: wavefolding, phase warp, FM between the oscillators, noise to POS, and a shaper.
  • One cursor for each note in the oscillator wave. With a chord, the page shows the position of each voice in the table. The page also shows the sum of the waves of all the voices.
  • Tags for stored tables, and a tag filter and a search on the wavetable page.
  • Ring modulation and AM between the oscillators, and a formant filter or a comb filter.
