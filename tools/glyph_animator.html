Glyph Animator

Draw a glyph as a list of frames. The knob picks the frame, as on the unit. For still glyphs, use the Glyph Editor.

Open site/js/mods/glyph-anims.js, or make a new animation.

Animation

Frame

Click or drag to paint. The first pixel you touch sets the colour of the stroke. Onion skin shows the previous frame faintly.

Frames

Dissolve replaces the frames between the two you give with steps from one to the other.

Knob

The knob shows the frame the unit picks: round(value x (frames - 1) / range). Play shows the frames in order.

Firmware format

Each frame is its columns, left to right. Each column is one 32-bit big-endian word, with the top row in the most significant bit. A frame taller than 32 rows uses more words per column. Import uses the size of this animation.
